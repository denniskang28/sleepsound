# 声音强度与参考声级计校准（v0.2.0）

## 在哪里查看

- 夜间监测：当前声音电平；未校准时同时显示本次能量平均、最高短时值、P95。
- 监测报告 → 夜间声音强度：上述三项汇总、带纵轴刻度的时间曲线、有效声级覆盖时长，可点击查看原始窗口。
- 录音详情：事件起止区间内的声音统计与声级图。它包括同期环境声音，不是分离后的鼾声声压；事件间的静默合并区间也包含在这个区间中。
- 播放波形仍是原有的归一化相对振幅，明确标注“非分贝尺度”，不伪装成声级图。

未校准默认使用相对数字电平 **dBFS**，满刻度参考为 0，通常是负数。通过校准后才使用**估计 dBA**，并显示验证范围。报告可切回 dBFS。只在新版本实际采集到连续声级数据的会话中提供这些统计，旧记录不从零散录音重建整晚结果。

## 手机快速试用

安装 v0.2.0 后，开始一次约 30 秒的监测，在手机旁用不同音量说话，再结束并查看报告。监测页应有实时相对电平，报告应有三项声级统计与刻度图。短会话仍会提示睡眠报告数据不足，但不影响查看已采到的声级数据；无需等待 3 小时。这个试用只检查功能和声音变化，不能检验绝对声级准确度。

若已经校准而显示 `< 下限`、`> 上限` 或平均值为空，先查看报告中的验证范围说明，也可切换“相对 dBFS”。麦克风或录音配置不匹配时会明确提示并回退为 dBFS，应使用当前实际配置重新比对，不要直接抄用其他手机的修正值。

## 校准操作

1. 设置 → 声音校准。结束当前夜间监测和历史录音播放；校准时保持应用可见，离开或切后台会停止本组采集，不保存原始校准音频。
2. 准备有校准记录、量程覆盖卧室低声级的参考声级计，设置 **A 计权 LAeq**，以及另一台设备连接的音箱。播放稳定粉红噪声。两个麦克风尽量靠近、互不遮挡、距声源相近，避免手持和移动。
3. 确认仪器设置后开始本组采集，并同步启动参考仪器。手机剔除约 0.975 秒滤波预热，然后采集 31 个窗口（30.225 秒）；保持声源全程稳定，完成后停止参考仪器，输入该稳定区间的 LAeq。
4. 至少完成三组；相邻参考值至少相差 5 dB，整体跨度至少 15 dB。可输入范围 25–90 dBA，但参考仪器量程和背景声必须实际允许该测量；不能因为输入框接受 25 就认为设备能准确测量 25 dBA。
5. 填写参考声级计型号或编号。向导检查后保存并启用。已有校准在新一轮通过并保存前继续保留，也可单独停用。
6. 校准保存在本机，通常不需要每晚再带参考仪器；麦克风、录音处理、系统版本等改变后重新校准。每晚床头距离、方向和手机壳遮挡尽量一致。

一致性检查：每组升序 P95−P5 不超过 3 dB；修正量取各组“参考 LAeq − 手机 A 计权数字电平”的中位数；各组应用同一修正量后的最大偏差不超过 2 dB。这些数值是当前产品的工程验收阈值，不是仪器精度认证。相同粉红噪声的多音量比对并不能消除手机频响、底噪和方向性误差。

不能使用文件名标注的“60 dB 音频”当作已知声压，也不能假设另一台未校准手机是真值。标准声学校准器需要尺寸适配的测量麦克风，不直接套在手机收音孔上。

## 计算口径

- 原始采集 16 kHz、PCM16、单声道，每 15,600 个样本为一个不重叠的 0.975 秒窗口，与现有声音模型共享输入，避免二次占用麦克风。
- 数字电平：`10 log10(mean((PCM/32768)^2))`。不是 `20 log10(原始整数幅度)`。
- A 计权：模拟 A 计权六个极点经双线性变换得到三段双二阶滤波，在 1 kHz 归一化。滤波状态跨窗口保持；每次重新开麦或配置改变后剔除第一个窗口预热。16 kHz 采音只覆盖 8 kHz 以下，滤波近似及整套设备不声明符合 IEC 声级计标准。
- 校准和夜间采集使用同一 `MeasurementInput`；优先 UNPROCESSED，否则 VOICE_RECOGNITION，并尝试禁用可控制的 AGC/降噪。设备自身仍可能有无法控制的音频处理，需要参考仪器实测。
- 能量平均：`10 log10(sum(duration × 10^(level/10)) / sum(duration))`，不直接求 dB 算术平均。
- 最高短时值：有效 0.975 秒窗口电平的最大值，不是瞬时声压峰值，也不是标准 Fast/Slow 时间计权最大值。
- P95：按窗口有效时长加权的**升序**第 95 百分位，95% 有效时长的电平不超过该值；不是声学中“95% 时间被超过”的 L95。实时 P95 使用 0.1 dB 直方图，报告使用精确窗口排序。
- 全零输入标记无有效信号，接近 PCM 满刻度的输入标记过载，两者不产生可用声级。系统静音/占用、暂停、中断、滤波预热均不补零，不拼接曲线，报告区分声级覆盖与有效采音时长。真实安静但非零的信号仍可计算 dBFS，不据此宣称已经超过手机底噪。
- 曲线最多分 240 个时间桶，竖线为桶内最小–最大值，点为声能平均；空时间桶留空。点击查询原始窗口，无数据处不吸附到邻近有效点。
- 校准后的范围外数值只显示 `< 下限` / `> 上限`；若整段包含范围外时段，平均和 P95 暂不显示，用户可切回 dBFS 查看相对统计。

## 持久化与兼容

Room 从版本 1 非破坏性升级至版本 2，新增 `sound_levels` 与 `sound_calibrations`，保留会话、录音、标签和收藏。每约 5 秒批量保存声级窗口，结束时刷新剩余数据；恢复中断会话时剔除最后心跳之后的窗口。

每个窗口引用采集时选定的校准 ID。配置签名包含系统构建、输入设备类型/地址/名称、音源、采样配置、音频处理和算法版本；无法识别或不匹配就不使用校准。整晚混合不同校准来源时，统一汇总为 dBFS。新校准、停用校准不改写旧报告。

删除或到期清理音频保留声级统计；删除会话级联删除声级窗口；清除全部数据同时移除校准记录及当前配置。校准不录制文件，不上传数据，不增加网络权限。

## 仍需真机与仪器验证

模拟器和合成音调只验证计算、迁移及交互，不能证明 S30 的声级准确度。实际交付精度需用目标手机与可靠声级计，在安静卧室、多个声级及不同频谱下比对，并验证录音处理、底噪、过载、系统升级和整夜稳定性。
